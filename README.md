### Objetivo Profissional  
Busco uma oportunidade como Desenvolvedor Full Stack para aplicar e ampliar meus conhecimentos no desenvolvimento de aplicações web e mobile, utilizando tecnologias como React, React Native, Node.js e PostgreSQL, entre outras ferramentas do ecossistema JavaScript/TypeScript. Tenho interesse em participar de todas as etapas do desenvolvimento de software, desde a criação de interfaces intuitivas até a implementação de APIs, regras de negócio e integração com bancos de dados.
